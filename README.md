# Thingual

**Learn the world, one thing at a time.**
Мобільний застосунок для вивчення мов через предмети навколо: наводиш камеру на річ — бачиш слово мовою, яку вчиш, чуєш вимову, а слово з твоїм фото потрапляє в особистий словник. Щодня весь світ фотографує одне й те саме слово (Daily Drop), а карта показує, як цей предмет виглядає і звучить у різних країнах.

Expo SDK 58 · React Native 0.88 · Expo Router · TypeScript · iOS, Android і Web з однієї кодової бази.

## Запуск

```bash
npm install
npx expo start          # QR-код для Expo Go, або натисни w для веб-версії
```

- **Телефон:** встанови Expo Go і відскануй QR-код.
- **Браузер:** `npx expo start --web` або зібрана версія: `npx expo export -p web` → папка `dist`.
- Для нативних модулів (знімок листівки, мовлення) потрібна development build: `npx eas-cli@latest build --profile development`.

## Спільнота (Supabase)

Профілі, підписки, дописи й відповіді (як у Threads), вподобання, скарги, блокування та фото зберігаються в Supabase (проєкт `thingual`, регіон eu-central-1). Схема — `supabase/migrations/20261021120000_social.sql`, доступ обмежено Row Level Security, фото — у публічних бакетах `avatars` і `posts`, кожен користувач пише лише у свою папку.

Акаунт створюється без реєстрації через **анонімний вхід Supabase**. Він має бути увімкнений: Supabase → Authentication → Sign In / Providers → **Allow anonymous sign-ins**.

## Камера

У браузері розпізнавання працює прямо на пристрої: TensorFlow.js + COCO-SSD шукає предмети в живому відео й ставить на них точки. На телефоні в Expo Go камера робить фото, а слово визначає сервер розпізнавання (якщо підключений) або ти обираєш його сама. Живі точки в нативній версії потребують development build з моделлю на пристрої.

## AI-розпізнавання

Функція `recognize` уже розгорнута в Supabase (код — `supabase/functions/recognize`). Їй потрібен лише ключ Anthropic:

1. Візьми ключ на [console.anthropic.com](https://console.anthropic.com) → API Keys.
2. Supabase → проєкт `thingual` → **Edge Functions → Secrets** → додай `ANTHROPIC_API_KEY`.
3. Необов’язково: `VISION_MODEL` (за замовчуванням `claude-haiku-5-5`).

Ключ живе тільки на сервері, у застосунку й репозиторії його немає. Без ключа камера пропонує обрати слово вручну.

## Запуск у продакшен — чекліст

**Вже працює:** синхронізація прогресу (таблиця `user_state`, вхід посиланням на email), PWA (встановлення на телефон, офлайн), AI-модерація фото (`moderate`), AI-співрозмовник (`chat`), розпізнавання (`recognize`), ліги (`league_xp`), звіти про помилки (`client_errors`), політика конфіденційності й умови (`/legal/privacy`, `/legal/terms`), автотести (`npm run test:e2e`) і CI на GitHub Actions.

**Що треба зробити власниці проєкту:**
1. Supabase → Authentication → URL Configuration → **Site URL** = `https://thingual.vercel.app` (і додати його в Redirect URLs). Без цього посилання для входу з email вестиме на localhost.
2. Supabase → Edge Functions → Secrets: `ANTHROPIC_API_KEY` (вже є). За бажання `CHAT_MODEL`, `MODERATION_MODEL`.
3. Vercel → Settings → Environment Variables: `EXPO_PUBLIC_CONTACT_EMAIL` — контактна адреса для політики конфіденційності.
4. Власний домен: Vercel → Domains; потім оновити Site URL у Supabase і `SITE_URL` у `src/lib/api.ts`.
5. App Store / Google Play: акаунти розробника (Apple $99/рік, Google $25), потім `npx eas-cli@latest build -p all --profile production` і `npx eas-cli@latest submit`.
6. Оплати Thingual Max: акаунт RevenueCat + продукти в App Store Connect / Google Play Console, потім підключити `react-native-purchases` (потрібна development build).
7. Перевірка перекладів носіями мов (дані — `src/data/words`, `src/data/phrases`).

## Що лишається для продакшену

- підключити Supabase Auth (анонімні акаунти) і синхронізацію словника та публікацій з таблицями з `supabase/migrations`;
- модерація фото (AI-фільтр + PhotoDNA) у функції перед публікацією;
- RevenueCat для реальних покупок, push-сповіщення Drop через APNs/FCM;
- переклад інтерфейсу ще на 14 мов (Crowdin).
