# Thingual

**Learn the world, one thing at a time.**
Мобільний застосунок для вивчення мов через предмети навколо: наводиш камеру на річ — бачиш слово мовою, яку вчиш, чуєш вимову, а слово з твоїм фото потрапляє в особистий словник. Щодня весь світ фотографує одне й те саме слово (Daily Drop), а карта показує, як цей предмет виглядає і звучить у різних країнах.

Expo SDK 58 · React Native 0.88 · Expo Router · TypeScript · iOS, Android і Web з однієї кодової бази.

## Що всередині

| Розділ | Що вміє |
| --- | --- |
| **Онбординг** | анімоване вітання з колажем справжніх фото, вибір мов, мети, фото-квіз на 6 питань (визначає рівень, пропущені слова одразу йдуть у словник), запит камери |
| **Камера** | режими «Предмет», «Сцена», «Текст», «Галерея», «Drop»; дихаюча точка розпізнавання; демо-видошукач зі справжніми фото, якщо камери немає; ліміт AI-сканувань для Free |
| **Картка слова** | паралакс-фото, артикль, латинізація, IPA, озвучення (звичайне й повільне), приклад речення, тренування вимови з оцінкою, «Як це звучить у світі» 16 мовами, фото зі світу, пов’язані слова, нотатка, колекції, листівка, публікація |
| **Словник** | фото / список / місця, фільтри (нові, складні, вивчені, з Drop), колекції, пошук будь-якою мовою, тематичні набори, експорт CSV/Anki (Plus) |
| **Навчання** | FSRS (як в Anki), 7 типів вправ: фото→слово з перевертанням, аудіо→фото, слово→фото, написати, сказати, зібрати речення, артикль; «Знайди поруч» за 60 секунд; прослуховування без рук; серії, графік тижня |
| **Daily Drop** | одне слово для світу щодня, таймер 3 хв, позначка «пізніше», механіка «опублікуй, щоб побачити», карта й «як світ це називає», колаж тижня |
| **Світ** | карта (Leaflet + монохромні тайли CARTO, кластери) з шарами Drop / будь-яке слово / поруч / друзі; стрічка Друзі / Світ / Колекції, челендж тижня, реакції без публічних лічильників, «Вивчити це слово», скарга й блокування |
| **Профіль** | анонімний нікнейм і градієнтний аватар, статистика, досягнення, друзі й запрошення, мої публікації, необов’язкова прив’язка акаунта |
| **Налаштування** | мови, рівень, щоденна ціль, голос, сповіщення, тема (світла/темна/системна), сімейний режим з PIN, експорт і видалення даних, демо-режим |
| **Thingual+** | екран підписки з планами (тестовий режим), ліміти Free з ТЗ |
| **Безпека** | вікова перевірка перед першою публікацією (лише вікова група), заборона публікацій до 13 років, геолокація округлюється до ~2 км і показується лише місто |

Усі фото в демо-контенті — справжні знімки з [Unsplash](https://unsplash.com/license) з підписами авторів. Слова: 38 концептів × 16 мов (en, uk, es, pt, de, fr, it, pl, tr, zh, ja, ko, ar, hi, id, vi) з артиклями й латинізацією. Інтерфейс повністю перекладено англійською та українською; інші мови інтерфейсу підключаються файлами в `src/i18n`.

## Запуск

```bash
npm install
npx expo start          # QR-код для Expo Go, або натисни w для веб-версії
```

- **Телефон:** встанови Expo Go і відскануй QR-код.
- **Браузер:** `npx expo start --web` або зібрана версія: `npx expo export -p web` → папка `dist`.
- Для нативних модулів (знімок листівки, мовлення) потрібна development build: `npx eas-cli@latest build --profile development`.

## Розпізнавання (бекенд)

Без сервера застосунок працює в демо-режимі: на демо-фото слово відоме, а для власних фото відкривається вибір слова (шлях «низька впевненість» з ТЗ). Щоб увімкнути справжнє AI-розпізнавання:

```bash
supabase link --project-ref <твій-проєкт>
supabase db push                                  # схема з supabase/migrations
supabase secrets set ANTHROPIC_API_KEY=sk-...
supabase functions deploy recognize
```

Потім створи `.env` за прикладом `.env.example`:

```
EXPO_PUBLIC_RECOGNIZE_URL=https://<project>.supabase.co/functions/v1/recognize
EXPO_PUBLIC_SUPABASE_ANON_KEY=<anon key>
```

## Структура

```
app/                 екрани (Expo Router)
  (tabs)/            Світ, Слова, Камера, Навчання, Я
  onboarding.tsx     вітання, мови, мета, квіз, камера
  word/[id].tsx      картка слова
  review.tsx         сесія повторення (FSRS, 7 вправ)
  drop.tsx           Daily Drop і reveal-карта
  find.tsx           «Знайди поруч»
  postcard/[id].tsx  листівка для сторіз
src/
  data/              концепти 16 мовами, фото, соціальні дані, календар Drop
  store/useApp.ts    стан (zustand + AsyncStorage), ліміти Free, серії
  lib/               FSRS, озвучення, розпізнавання, мовлення, геолокація
  components/        дизайн-система, карта, картки, шторки
  i18n/              en, uk
supabase/            схема БД з RLS і функція recognize
```

## Що лишається для продакшену

- підключити Supabase Auth (анонімні акаунти) і синхронізацію словника та публікацій з таблицями з `supabase/migrations`;
- модерація фото (AI-фільтр + PhotoDNA) у функції перед публікацією;
- RevenueCat для реальних покупок, push-сповіщення Drop через APNs/FCM;
- переклад інтерфейсу ще на 14 мов (Crowdin).
